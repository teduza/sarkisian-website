# Aleksandr Sarkisian (Sargsyan) — Official Personal Website

Official personal website, identity graph, and intellectual property showcase of Aleksandr Sarkisian (Sargsyan), founder and director of M.A.R.S. COMPANION LLC.

🌐 **Production URL:** [https://sarkisian.teduza.com/](https://sarkisian.teduza.com/)

---

## ⚡ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **SEO & Structured Data:** Semantic HTML5, Schema.org JSON-LD Graph (`Person`, `Organization`, `Product`, `ScholarlyArticle`), Open Graph, Twitter Cards, `sitemap.xml`, `robots.txt`
- **Localization:** English (default) & Russian (`en` / `ru`)

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Type Checking & Verification
```bash
npm run lint
```

### 4. Production Build
```bash
npm run build
```
The optimized static build will be generated in the `dist/` directory.

## 📦 Pushing to GitHub

To upload this repository to your personal GitHub account:

```bash
# 1. Initialize git
git init

# 2. Add all project files
git add .

# 3. Create your initial commit
git commit -m "feat: official personal website of Aleksandr Sarkisian"

# 4. Set default branch to main
git branch -M main

# 5. Link your GitHub repository (replace with your repo URL)
git remote add origin https://github.com/teduza/sarkisian-website.git

# 6. Push code
git push -u origin main
```

---

## 🌐 Deployment (Cloudflare Pages / Vercel / Netlify)

1. Connect your GitHub repository to **Cloudflare Pages** or **Vercel**.
2. Configure build settings:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. Bind your custom domain: `sarkisian.teduza.com`
